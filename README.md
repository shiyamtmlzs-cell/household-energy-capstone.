# Household Energy Consumption Analysis

## Project
CA4 Business Analytics Capstone.

## Objective
Analyse household electricity consumption and explore
patterns associated with household size, temperature,
AC availability and peak-hour usage.

## Technologies
Python, Pandas, Plotly and Streamlit.

## Dataset
The project uses household_energy_consumption.xlsx.
The original public-domain source must be verified and
approved by the faculty before final submission.

## Run the dashboard
Install dependencies using:
pip install -r requirements.txt

Run:
streamlit run app.py
